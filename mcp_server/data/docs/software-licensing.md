# Software Licensing Policy

## Approved catalog
Apps in the Self Service catalog are already licensed and can be installed without approval.

## Requesting new software
For tools not in the catalog, open a request with the business justification and the expected number of users. Security reviews the tool's data handling, then finance approves the cost. Expect two to three business days.

## Renewals and unused licenses
Licenses not used for 60 days are reclaimed automatically so they can be given to someone else. Team leads get a renewal reminder 30 days before an annual contract ends.

## Open-source tools
Open-source tools are allowed for development work, but their licenses must be checked before the tool ships inside a customer-facing product.
