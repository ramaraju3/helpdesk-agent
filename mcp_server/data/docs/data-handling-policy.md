# Data Handling Policy

## Classification levels
Company data has three levels. Public: safe to share with anyone. Internal: fine to share inside the company. Confidential: customer data, salaries, contracts and source code, which only the people who need it may access.

## Sharing files outside the company
Internal files must not be sent to personal email accounts. Confidential files may be shared with external partners only through the approved secure share link, which expires after 14 days. Never paste confidential data into public websites or unapproved AI tools.

## USB drives and removable media
USB storage is blocked on company laptops by default. If you must move large files to a partner, use the secure share link instead. Exceptions need written approval from the security team.

## Suspected data leak
If confidential data may have reached the wrong person, report it to the security team within one hour. This is always high severity.
